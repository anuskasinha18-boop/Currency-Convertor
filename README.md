# Currency Converter

A beautiful, modern currency converter application featuring a dark neon aesthetic. Built with HTML, Tailwind CSS, and Vanilla JavaScript.

## Features

- **Live Exchange Rates**: Fetches real-time exchange rates using the `currency-api`.
- **Neon Dark Mode UI**: A stunning glowing interface with neon purple and green accents.
- **Swap Functionality**: Easily swap the "From" and "To" currencies with a single click.
- **Quick Rates**: Automatically displays current conversion rates for popular pairs from your base currency.
- **Responsive Design**: Works perfectly on both desktop and mobile devices.

## Setup

Simply open `index.html` in any modern web browser. No local server or build tools required.

## Tech Stack

- **HTML5**
- **Tailwind CSS** (via CDN)
- **Vanilla JavaScript** (ES6+)
- **FontAwesome** (Icons)
- **Google Fonts** (Outfit)
